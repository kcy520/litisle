###### 4.2 检索转正与问答分流链路

- [x] 知识库检索工具（2.2 工具④）由占位转正：Embedding → TopK 检索 + 相似度阈值过滤 → 引用可见性回查 → 组 prompt → LLM → 回答 + 引用卡片；问答作为 2.3 意图路由的分流目标之一，复用单一入口 /ai/xiaoyue/chat，**不另设独立端点**（消除与本清单 2.3 的路径双重定义）
  - 引用铁律：引用必须可溯源；引用返回带文章 updateTime/版本号，与切片构建时版本比对，不一致则移除引用或标注「内容已更新」（Q75 口径）；引用内容下架即失效
  - 降级铁律（Q54）：RAG 不可用降级为无引用回答并显著标注「未引用站内内容」；涉及事实性结论只答「暂无相关资料」，不得混入模型自身知识冒充站内回答
  - 匿名问答配额：Redis 日计数键 `ai:quota:anon:{ip哈希}`（定档见 P5，2026-11-15）；purpose=QA 走计量预算链路；模型原始输出不直接展示，只出结构化回答
  - ✅ 2026-11-15：XiaoyueTools 工具④ searchKnowledgeBase 转正（注入 ObjectProvider<RagSearchService>，rag.enabled=false Bean 缺席 → RAG_DEGRADED_HINT 提示模型无检索直接回答并标注；检索异常同样降级 hint，不阻断 Agent 循环）；RagSearchService.searchForPrompt（embed 查询向量化 → ChunkIndexClient.knnSearch TopK=top-k=5 → min-score=0.6 相似度过滤 → verifyChunk 引用回查（ContentClient 回查失败/非已发布/非公开 → removed=true 引用移除；contentHash 与摄入时比对不一致 → 「内容已更新」过期标注，Q75 口径；下架即失效由门控删除+回查双保险）→ passages 组装含【引用N】溯源编号与使用规则 → RagContext.record 写入本轮引用上下文）；引用卡片：RagContext（ThreadLocal，XiaoyueChatService.chat ⑨ begin/finally drain 兜底清理防线程池串号）→ finalizeAgentOutput 成功分支 setCitations（XiaoyueCitationDTO：articleId/title/contentHash/removed，litisle-api 契约新增）；匿名问答（P5）：XiaoyueChatRequest 增 anonIpHash 字段，chat() 匿名放行（userId 为空仅 purpose=QA 且 anonIpHash 必传）→ AiUserQuotaService.tryAcquireAnonymous（Redis key=ai:quota:anon:{ipHash}:{yyyyMMdd} INCR + 首次 expire 24h，超限拒绝 80003 + recordQuotaExceeded 打点；Redis 异常降级放行不阻断问答）；计量/预算/缓存/降级链路复用 2.3~2.5 既有口径不变（不另设独立端点，/ai/xiaoyue/chat 复用）；运行态验证项（待联调）：Ollama/ES/模型 api-key 就绪后的端到端摄入与引用问答验证见 next_verify.md（AI-V1）；编译验证已通过（2026-11-15，mvn -pl litisle-ai,litisle-review -am compile）
